# Financial ratio summary dataset

`financial_ratio_summary.csv` contains 54 rows: 2 companies × 3 financial years × 9 ratios.

Fields: `company`, `financial_year`, `analysis_category`, `ratio`, `value`, `unit`. `x` represents a multiple and `%` represents a percentage. For example, a value of `10.21` with unit `%` means `10.21%` (not `0.1021`).

The figures are **rounded summary results** transcribed from the accompanying project's analysis. This is not an original financial statement dataset and should not be used to reconstruct precise ratio calculations. For definitions, source reconciliation and limitations, consult the [report](../report/Financial_Analysis_Report.pdf).
